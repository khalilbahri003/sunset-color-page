# استوديو ألوان الغروب

صفحة ويب عربية صغيرة لتجربة تدرّج لوني مباشرًا. غيّر اللونين أو زاوية التدرّج، اختر لوحة جاهزة، ثم انسخ سطر CSS.

## التشغيل

افتح `index.html` في متصفح حديث. لا تحتاج إلى تثبيت برامج أو مكتبات.

## الملفات

- `index.html` — بنية الصفحة وعناصر التحكم.
- `style.css` — الألوان والتنسيق المتجاوب.
- `script.js` — تحديث المعاينة ونسخ CSS.
